## 七维结构

每位“小明”都按统一七维展开：

1. **岗位职责（Job Definition）** — 含“不做什么”边界
2. **Skill 清单（Atomic Skills）** — 原子 Skill + 职能映射 + 跨员工边界
3. **工作流（Execution Workflow）** — 3 步主流程 + HITL 节点 + 异常路径
4. **工具权限（Tool Permissions）** — R/W/X 三级；X 权限必须匹配 HITL
5. **KPI** — 时效 / 准确率 / 成本 / 业务结果 / 步骤经济性五维
6. **审计链路（Audit Trail）** — 数据采集 / 决策记录 / 人工裁决三层
7. **业务交付物（Business Deliverables）** — 看板 / 证据包 / 决策卡 / 数据接口

## 步骤经济性原则

> **减步骤不是减能力，而是把能力打包到更少的调度节点里。**

| 约束 | 标准 |
|---|---|
| 单个小明主工作流步骤 | ≤ 3 步 |
| 单场景主体步骤 | ≤ 15 步 |
| HITL 节点 | 每个主流程 ≤ 3 个 |
| 协同方式 | 主导 Agent 1 个 + 核心协同 Agent 2 个，其他 Agent 按阈值触发 |

## 治理原则

> **可读、可判、可建议；高风险动作必须可确认**

所有涉及对外发送、广告预算调整、合同承诺、融资申请、银行数据共享、采购/补货等 X 权限调用，前置必须有 HITL 决策卡。
