## 核心设计原则

| 原则 | 说明 |
|---|---|
| 步骤经济性 | 每位小明的主工作流尽量控制在 3 步以内，降低现场展示与系统调度成本 |
| 接力节俭 | 多 Agent 协同尽量收敛为少量关键交接点，避免链路过度发散 |
| 人在回路 | 融资提交、物流切换、预算调整、对外发送等高风险动作保留人工确认 |
| 结果导向 | 每个场景最终都要落到可执行的业务交付物，而不是只展示推理过程 |
| 白盒可信 | 关键单据、报告、流水、轨迹与 AI 决策快照需要可追溯、可复核、可审计 |

## 五分钟 Demo 主线

当前重点 Demo 为：

> 将一只景德镇手工陶瓷茶杯，从景德镇工厂端合规、可控、可审计地交付到洛杉矶 C 端买家。

该 Demo 调用六类 AI 小明：

| AI 小明 | 主要任务 |
|---|---|
| 主控编排小明 | 识别目标、拆解任务、调度接力 |
| 经营评估小明 | SKU 入档、包装与履约判断、采购资金缺口评估 |
| 跨境合规审计小明 | HS/FDA 预审、出口退税封包、Sales Tax 与数据合规判断 |
| 全球物流调度小明 | 端到端路线生成、海空方案对比、异常切换决策 |
| 多语言营销专家小明 | 洛杉矶达人筛选、Brief 与 Listing 生成、红人资产锁定 |
| 经营分析小明 | 全链路成本归集、单杯利润核算、今日行动清单 |
| 白盒存证小明 | 证据采集、哈希存证、审计回放 |

现场展示控制为：

| 项目 | 设计 |
|---|---|
| 展示时长 | 约 5 分钟 |
| 接力链路 | 主控派单 → 合规放行 → 经营刷新 → 存证闭环 |
| 观众交互 | 开始交付、确认物流切换、生成行动清单 |
| 最终交付物 | 履约方案、合规包、营销启动包、利润行动清单、审计存证包 |
